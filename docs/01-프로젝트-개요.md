## 새 게임 추가 순서

1. `public/data/games/{이름}.json` — 문제 데이터
2. `src/game/{이름}/{이름}Engine.ts` — BaseEngine 상속
3. `src/pages/games/{이름}Page.tsx` — 레벨 선택 + Canvas
4. `src/App.tsx` — 라우트 1줄 추가
5. `src/data/gameRouteMap.ts` — 매핑 1줄 추가
