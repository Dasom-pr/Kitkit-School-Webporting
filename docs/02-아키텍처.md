# 아키텍처 문서

## 게임 엔진 구조

모든 게임은 `BaseEngine`을 상속하는 구조다.

```
BaseEngine (추상 클래스)
├── canvas, ctx
├── gameScale (화면 비율 자동 계산)
├── resize() — DPR 설정, gameScale 계산
├── toGameCoords(x, y) — 포인터 좌표 → 가상 좌표 변환
├── loop() — requestAnimationFrame 루프
├── handlePointerDown/Move/Up — 이벤트 → toGameCoords → onPointerDown/Move/Up
├── onComplete?: () => void — 게임 완료 콜백
└── gameState: 'playing' | 'complete'

구체 클래스 (예시)
└── ReadingBirdEngine extends BaseEngine
    ├── start() — 이벤트 등록, loop(), loadLevel()
    ├── loadLevel() — JSON 로드, setupProblem()
    ├── setupProblem() — 문제 세팅, 사운드 재생
    ├── onPointerDown(x, y) — 카드 탭 처리
    ├── update(t, dt) — 프레임별 상태 업데이트
    └── draw() — Canvas 렌더링
```

### 가상 해상도 시스템

```
실제 화면: 예) 1280×800
가상 해상도: 2560×1800 (GAME_WIDTH × GAME_HEIGHT)
gameScale = min(1280/2560, 800/1800) = 0.444...

그리기 전:
ctx.translate(ox, oy)   ← 중앙 정렬 오프셋
ctx.scale(gameScale, gameScale)  ← 스케일 적용

이후 모든 좌표는 2560×1800 기준으로 작성하면 됨
```

## 셸 통합 패턴

커리큘럼에서 게임을 시작할 때 URL에 파라미터가 붙는다.

```
/game/readingbird?level=12&from=shell&levelID=en-US_L_6&day=12&gameIndex=0
```

### useShellParams 훅

```tsx
const { shellLevel, isFromShell, onGameComplete, shellBack } = useShellParams()
```

| 반환값 | 설명 |
|--------|------|
| `shellLevel` | URL의 `level` 파라미터 (number) |
| `isFromShell` | `from=shell` 존재 여부 |
| `onGameComplete()` | 완료 시 → 진행상태 저장 → 커리큘럼 복귀 |
| `shellBack()` | 뒤로 가기 |

### 올바른 Page 패턴

```tsx
const { shellLevel, isFromShell, onGameComplete, shellBack } = useShellParams()
const [level, setLevel] = useState(0)

const startLevel = useCallback((lvl: number) => {
  setLevel(lvl)
  setShowComplete(false)
}, [])

// 셸에서 자동 시작
useEffect(() => {
  if (shellLevel && level === 0) startLevel(shellLevel)
}, [shellLevel, level, startLevel])

// 완료 시 커리큘럼 복귀 + 진행상태 저장
useEffect(() => {
  if (showComplete && isFromShell) onGameComplete()
}, [showComplete, isFromShell, onGameComplete])
```

> ⚠️ 잘못된 패턴: `const { level: shellLevel } = useShellParams()`
> `useShellParams()`에는 `level` 프로퍼티가 없다 → `undefined`

## 라우팅 구조

```
App.tsx
├── / → LauncherPage
├── /coop/:levelID/day/:day → MainScenePage (커리큘럼 셸)
├── /game/{이름}?level=N → 각 게임 Page
├── /book/:id → BookViewerPage
└── /video/:id → VideoPlayerPage
```

게임명 → 라우트 매핑: `src/data/gameRouteMap.ts`의 `resolveGameRoute()`
