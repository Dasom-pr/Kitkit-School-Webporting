### 버그 1 — WordWindow: answer 항상 0

| 항목 | 내용 |
|------|------|
| 게임 | WordWindow |
| 파일 | `public/data/games/wordwindow.json` |
| 증상 | 어떤 보기를 눌러도 첫 번째(index 0)만 정답으로 처리됨 |
| 원인 | TSV의 `#rightAnswer` 컬럼이 **1-based** (1,2,3,4)인데, 스크립트에서 그대로 저장 → 모든 answer가 1이상이어야 하는데 0-based index와 혼동 |
| 수정 | JSON 재생성 시 `answer = parseInt(rightAnswer) - 1` 적용 |
| 검증 | Level 1 Problem 1: `rightAnswer=4` → `answer=3` → `examples[3]="9"` (6+3=9 ✓) |
